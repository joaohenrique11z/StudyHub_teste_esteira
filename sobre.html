Bons estudos :) Estatísticas Tarefas Sobre Perfil

Sobre o Projeto

Este sistema foi desenvolvido com HTML, CSS e JavaScript com o objetivo de auxiliar estudantes na organização dos estudos.

O usuário pode criar tarefas, registrar o tempo de estudo com um cronômetro e visualizar estatísticas de desempenho.

Os dados são armazenados localmente utilizando localStorage.
